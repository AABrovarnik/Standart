# Vibe-ready DoD Package for GitHub

Этот каталог подготовлен для публикации в репозитории `AABrovarnik/Standart`.

## Состав пакета

1. `VIBE_READY_DOD_MASTER.md` — основной (master) стандарт: базовый DoD + таблицы LITE/STRICT.
2. `VIBE_READY_DOD_STANDARD.md` — базовая версия стандарта (без сравнительного акцента).
3. `VIBE_READY_DOD_LITE_VS_STRICT.md` — отдельная сравнительная версия в формате двух таблиц.
4. `SOURCES_ANNOTATED.md` — список источников с краткими аннотациями по каждому.

## Рекомендация по публикации

Для «чистого» входа в репозиторий можно оставить в корне только:

- `VIBE_READY_DOD_MASTER.md`
- `SOURCES_ANNOTATED.md`

а остальные два файла перенести в подпапку `archive/` как рабочие промежуточные версии.
